# AAWA — PMSA Arts Fest 26-27 Website

Official portal and live dashboard for **AAWA '26** (PMSA Arts Fest 26-27), hosted by Munthajul Afnan Students' Association (MASA) at PMSA Wafy College Kattilangadi.

**Theme:** *When Values Speak*  
**Festival Dates:** *29 September, 30 September & 01 October 2026*  
**Meaning of AAWA:** *The Arabic word for "Voice" — where talent and art become the conscious voice of moral values and truth.*

### Key Features
- **Grand Hero Experience & Theme Philosophy**: 'AAWA: When Values Speak'
- **Live Leaderboard & Category Breakdown**: Real-time scores and standings
- **Official Results Center (`/results`)**: Live results feed filterable by Sub-Junior, Junior, Senior, and General categories
- **TV Broadcast Center (`/tv`)**: High-visibility big-screen display mode with live tickers
- **Stage Arena Display (`/screen`)**: Grand ceremony stage display
- **Administrative Adjudication Center (`/admin`)**: Secure jury and score entry workflow
